# Inbox: drop raw clips here

Upload your raw videos to this folder. On GitHub, go to "Add file", then "Upload files".
Then, in Claude Code, ask:

    /reels inbox/your-clip.mov --brief "what it's about + your call to action"

GitHub's website accepts files up to 25 MB. A 30-60 second phone clip in 1080p usually fits.
If yours is bigger, record in 1080p instead of 4K, or trim it first.
